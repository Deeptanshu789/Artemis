# Design specs (required gate)

**Dashboard visual UI must not be polished until these files exist and you confirm them.**

Drop your design markdown here (or replace the interim stubs):

| File | Purpose |
|------|---------|
| `dashboard-overview.md` | Session list, score cards, charts, spacing / type / color tokens |
| `session-detail.md` | Transcript + scorecard layout |
| `auth-shell.md` | Login / guest, nav, empty states |
| `extension-popup.md` | (Optional) Popup status + summary card |

## How to provide

1. Paste files into `design/`, **or**
2. Paste full markdown in chat and ask the agent to write them here.

Until confirmed, agents may only ship **route shells + data wiring** for the dashboard.
